The full syllabus

100 days in 8 phases. Each phase ends with a capstone that uses everything before it.

Nothing matches that. Try "http", "sort" or "M-Pesa".

Set up once, in about ten minutes

  1. Install Go 1.25 or newer from go.dev/dl. Check with go version.
  2. Get the course: 
    git clone https://github.com/sagebeme/100-Days-of-Go.git
cd 100-Days-of-Go
  3. Start Day 1: write your code in phase-1-terminal/day-001-mpesa-sms/starter and run go test ./phase-1-terminal/day-001-mpesa-sms/starter until it says ok.
  4. Then the kata: write kata/main.go and judge it with go run ./tools/kata 1.
  5. From Phase 6 you'll also need Node.js 24 for the React front end.

Commit your work every day. In three months you'll want to see how far you came.
